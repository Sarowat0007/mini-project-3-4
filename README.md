# Weather Finder

A simple, responsive weather application built with HTML, CSS, and JavaScript.

## Features
- Search for a city and view its current weather.
- Displays temperature, feels-like temperature, humidity, wind speed, and conditions.
- Save favourite cities in browser Local Storage.
- Loading, error, and empty states.
- Responsive layout for desktop and mobile.

## API
This project uses the free [Open-Meteo Geocoding API](https://geocoding-api.open-meteo.com/) to find city coordinates and the [Open-Meteo Forecast API](https://open-meteo.com/) to retrieve current weather. No API key is required.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Make sure you have an internet connection to retrieve weather data.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.
